# HR Analytics Dashboard | Tableau

## Project Overview
This project focuses on analyzing employee data and understanding workforce trends using Tableau. The dashboard provides insights into employee attrition, demographics, department distribution, and job satisfaction.

## Tools & Technologies
- Tableau
- Microsoft Excel

## Key Performance Indicators (KPIs)
- Total Employees: 1,470
- Attrition Count: 237
- Attrition Rate: 16.12%
- Active Employees: 1,233
- Average Employee Age: 37

## Dashboard Features
- Department-wise Attrition
- Employee Count by Age Group
- Job Satisfaction Rating
- Education Field-wise Attrition
- Attrition Rate by Gender and Age Group

## Dashboard Preview
![HR Analytics Dashboard](Dashboard-Screenshot.png)

## Project Objective
To analyze employee data through interactive visualizations and identify patterns in employee attrition and workforce distribution.
